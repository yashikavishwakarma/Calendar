# 📅 Calendar App

A modern and interactive calendar application built using React and TypeScript that allows users to select multiple dates and manage notes efficiently. The app focuses on clean UI, smooth user experience, and theme-based design.

---

## 🚀 Features

- 📆 Dynamic Calendar View  
  Displays the current month with proper alignment including previous and next month overflow days.

- ✅ Multi-Date Selection  
  Click to select/unselect dates and select multiple dates at once.

- 📝 Notes Management  
  Add notes to selected dates and visualize them with indicators on the calendar.

- 🎨 Theme Support  
  Fully customizable themes using CSS variables (includes dark TUF/Striver-style UI).

- ⚡ Smooth User Experience  
  Clean layout with conditional rendering (notes panel only appears when needed).

---

## 🛠️ Tech Stack

- Frontend: React + TypeScript  
- Styling: CSS Variables / Inline Styles  
- State Management: React Hooks
