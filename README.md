# 📅 Calendar App  

A modern and interactive calendar application built using React and TypeScript.  
It allows users to select multiple dates, manage notes, explore themes, and view festivals with a clean and smooth UI.

---

## 🌐 Live Demo  
https://calendar1-wxtk.onrender.com/

---

## 🚀 Features  

### 📆 Dynamic Calendar View  
Displays the current month with proper alignment, including previous and next month overflow days.

### ✅ Multi-Date Selection  
Select and unselect multiple dates easily with a single click.

### 📝 Notes Management  
Add notes to selected dates and visualize them with indicators on the calendar.

### 🎨 Theme Support  
Choose from 5 different themes to match your mood:
- Chill Vibes
- TUF Mode
- Grind Mode
- Aesthetic
- Midnight

### 🌐 Language Support  
Switch between two languages:
- English  
- Hindi  

### 🎉 Festival Section  
View festivals directly inside the calendar for better planning and awareness.

### ⚡ Smooth User Experience  
Clean layout with conditional rendering. Notes panel appears only when needed.

---

## 🛠️ Tech Stack  

- Frontend: React + TypeScript  
- Styling: CSS Variables and Inline Styles  
- State Management: React Hooks
