## 🚀 Quick Start - Let's Get Planning!

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation
```bash
# Clone the repo (or just download the files)
cd your-awesome-project

# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```

### Usage
1. **Pick Your Mood**: Choose from 4 amazing themes in the theme picker (Chill Vibes is default!)
2. **Switch Languages**: Click the language button for instant English ↔ Hindi toggle
3. **Add Notes**: Click dates, add text and emojis, save your memories in any language!
4. **Celebrate**: Check the Festival tab for holiday magic (available in both languages)
5. **Navigate**: Use arrow buttons to explore different months

## 🛠️ Tech Stack - The Magic Behind the Scenes

- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite for lightning-fast development
- **Styling**: Tailwind CSS + Custom CSS Variables
- **State Management**: React Hooks (useState, useEffect)
- **Icons & Emojis**: Native emoji support
- **Storage**: localStorage for note persistence
- **Responsive**: Mobile-first design approach
